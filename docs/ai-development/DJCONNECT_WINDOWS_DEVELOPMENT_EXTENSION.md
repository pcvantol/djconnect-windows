# DJConnect Windows development extension

`djconnect-windows` owns the Windows client implementation, presentation/runtime and Windows-local localization. DJConnect remains the product-authority for cross-component architecture and roadmap.

Use `docs/ARCHITECTURE.md`, `docs/DEVELOPMENT.md`, `run_tests.sh`, `global.json`, and the existing .NET/Windows CI workflows for local validation. Existing `.tde.yml` and Trusted Delivery evidence remain authoritative.
